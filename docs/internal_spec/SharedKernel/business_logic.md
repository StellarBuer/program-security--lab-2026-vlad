# ====== SHARED KERNEL SPECIFICATION ======

## Purpose
`SharedKernel` містить фундаментальні будівельні блоки, загальні для всіх bounded contexts проєкту:
- Базові класи сутностей та об'єктів-значень.
- Глобальні ідентифікатори (UUID базові типи).
- Базові класи винятків проекту.

## Core Components
- **`ABaseEntity`**: Базовий клас для всіх Aggregate Roots та сутностей, що містить іммутабельний `Uuid`.
- **`AValueObject`**: Базовий клас для об'єктів-значень (інкапсулює логіку порівняння за значенням).
- **`AGameEngineException`**: Головний базовий клас винятків для всього проєкту (від нього успадковуються винятки `ACCT`, `PROG`, `BTTL`).
