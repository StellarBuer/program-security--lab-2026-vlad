## 1. Scope (Область огляду)
Модель охоплює консольний клієнт (`Game.ConsoleClient`), серверний ASP.NET Core Web API (`Game.Api`), бізнес-логіку домену та взаємодію з реляційною базою даних через EF Core[cite: 9, 16, 19].
*Поза межами моделі:* фізична безпека хостинг-серверів та клієнтських операційних систем.

## 2. System Overview & DFD Elements
У системі виділені такі базові елементи діаграми потоків даних (DFD)[cite: 12, 13, 9]:
- **E1 Player** *(External Interactor)* — гравець, що взаємодіє з клієнтом[cite: 9].
- **P1 Console Client** *(Process)* — клієнтський додаток для надсилання запитів[cite: 9, 19].
- **P2 Web API Server** *(Process)* — серверний додаток (обробка JWT, маршрутизація, ігрова логіка боїв 5x5 та прогресії)[cite: 9, 18, 19].
- **D1 Game Database** *(Data Store)* — реляційна база даних (облікові записи, інвентар, стани персонажів)[cite: 9, 18].
- **F1 Client -> API** *(Data Flow)* — мережевий потік передачі даних (HTTP REST / SignalR)[cite: 9, 16].
- **TB1 Trust Boundary** — межа довіри між клієнтом (недовірена зона) та серверним API (довірена зона з Server Authority)[cite: 13, 9, 16].
