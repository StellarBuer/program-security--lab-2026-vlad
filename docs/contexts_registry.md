# Реєстр bounded contexts (модулів) проєкту

| Модуль (Context) | Сегмент винятків | Відповідальність | Статус |
| :--- | :--- | :--- | :--- |
| **Identity** | `IDNT` | Реєстрація, авторизація гравців, видача JWT токенів. | Draft |
| **Progress** | `PROG` | Збереження колекції персонажів, рівня акаунта, інвентарю та нагород. | Draft |
| **Battle** | `BTTL` | Логіка покрокового бою, розстановка на сітці 5х5, обчислення навичок. | Draft |
| **SharedKernel**| `CORE` | Спільні VO (UUID, базові абстракції), загальні винятки. | Active |
