# Tactics Game Engine (.NET Core / DDD)

Серверно-орієнтована покрокова тактична гра з кліент-серверною архітектурою, розроблена за принципами **Clean Architecture** та **Domain-Driven Design (DDD)**. 

Проєкт реалізує повний цикл взаємодії гравця з сервером: від автентифікації та прокачки до тактичних покрокових боїв на ігровій сітці.

---

## 🚀 Основний функціонал

- **Автентифікація та Безпека:** Реєстрація та вхід користувачів за поштою та паролем із використанням JWT-токенів.
- **Прогресія та Інвентарій:** Зберігання колекції персонажів гравця, нарахування досвіду, прокачка рівнів та збір нагород на боці сервера.
- **Тактична бойова система:**
  - Поле бою складається з двох блоків 5x5 (разом 50 клітинок).
  - Зостанова команди з 4 персонажів у спеціальних зонах 3x3 посередині кожного блоку.
  - Навички персонажів трьох типів: **звичайна**, **посилена** та **унікальна**.
- **Server Authority:** Вся ігрова логіка, перевірки ходів, валідність розстановки та розрахунок боїв виконуються виключно на сервері.
- **Консольний клієнт:** Зручний консольний інтерфейс для взаємодії з REST API сервера у першій версії проєкту.

---

## 🛠 Технологічний стек

- **Мова програмування:** C# (.NET 8 / .NET 9)
- **Серверна частина:** ASP.NET Core Web API
- **База даних та ORM:** Entity Framework Core (PostgreSQL / SQL Server)
- **Архітектура:** Domain-Driven Design (DDD), Clean Architecture, CQRS-підхід
- **Тестування:** xUnit, Moq
- **Кліентська частина:** C# Console Application
